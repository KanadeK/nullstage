# Changelog

All notable user-visible changes are recorded here. This project follows Semantic Versioning.

## [0.1.0] - 2026-08-30

### Added

- Strict, versioned JSON scenarios for measured stages, relative sources, microphone patterns, and physical search envelopes.
- Direct-field target/spill analysis with ranked contributors and declared off-axis rejection floors.
- Bounded deterministic position/aim optimization constrained by target working distance.
- Terminal, stable JSON, standalone SVG, and script-free HTML evidence.
- Policy exit `1`, invalid-input exit `2`, real pass/fail/invalid examples, cross-platform CI, and release-equivalent packaging checks.

### Security

- Duplicate-key, non-finite-number, unexpected-field, coordinate, reference, candidate-count, and no-overwrite validation at system boundaries.
