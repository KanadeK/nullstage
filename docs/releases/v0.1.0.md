# NullStage v0.1.0

NullStage turns a measured small-stage JSON file into inspectable microphone-spill evidence and a bounded candidate layout.

## First-release proof

- Three real result states: pass (`0`), below policy with evidence (`1`), and invalid input with repair guidance (`2`).
- The committed live-band fixture improves its worst modeled margin from `5.66 dB` to `8.82 dB` without leaving declared movement, aim, or target-distance limits.
- JSON, SVG, and script-free HTML are generated from the same analysis/optimization result.
- The runtime is offline and has no third-party dependency.

## Important boundary

NullStage is a direct-field 2D planning estimate. It does not model the room, frequency response, phase, performer movement, feedback, absolute SPL, or safety. Rehearse and measure every candidate before use.
